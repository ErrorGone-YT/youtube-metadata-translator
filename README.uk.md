# YouTube Metadata Translator

Інструмент командного рядка для YouTube-авторів: локалізує назви та описи відео 12+ мовами через нейромережу (CodeCraft/DeepSeek, Google Gemini, Ollama або локальна LM Studio), оновлює метадані відео, додає відео до плейлистів і ставить відкладену публікацію на потрібні дні тижня.

Працює на Windows та macOS. Усе, що потрібно — безкоштовно або майже безкоштовно.

> 🇬🇧 English guide: [README.md](README.md)
> 🇷🇺 Инструкция на русском: [README.ru.md](README.ru.md)

## Що знадобиться (~30 хвилин разової настройки)

1. **Python 3.10 або новіший** — мова, якою написаний скрипт.
2. **Google-акаунт**, якому належить YouTube-канал.
3. **Ключ для перекладу** — один із варіантів:
   - [CodeCraft API](https://codecraftapi.com) — найстабільніший варіант, є безкоштовний тариф;
   - ключі **Gemini** від Google — безкоштовні, але модель іноді перевантажена.
4. ~30 хвилин часу (робиться один раз).

## Крок 1. Встановіть Python

### Windows

1. Зайдіть на https://www.python.org/downloads/ та натисніть жовту кнопку **Download Python 3.x.x**.
2. Запустіть інсталятор.
3. **НАЙВАЖЛИВІШЕ:** на першому екрані поставте галочку **"Add python.exe to PATH"** (внизу вікна).
4. Натисніть **Install Now**.
5. Перевірка: `Win + R` → `cmd` → Enter, наберіть `python --version`. Має показати щось на кшталт `Python 3.13.1`.

### macOS

1. Зайдіть на https://www.python.org/downloads/ — сайт сам запропонує версію для Mac. Встановіть як звичайну програму.
2. Перевірка: відкрийте **Термінал** (Cmd + Пробіл, наберіть «Термінал»), наберіть `python3 --version`.
3. `tkinter` (потрібен для вікна вставки опису) входить в інсталятор з python.org автоматично.

## Крок 2. Встановіть бібліотеки

Відкрийте термінал у папці проєкту та виконайте:

```
pip3 install -r requirements.txt
```

(Windows: `pip install -r requirements.txt`)

## Крок 3. Створіть ключі Google (client_secrets) — найдовший крок

Це ключі, які дозволяють скрипту керувати **вашим** YouTube-каналом. Робиться один раз.

### 3.1. Створіть проєкт у Google Cloud

1. Зайдіть на https://console.cloud.google.com під Google-акаунтом каналу.
2. Зверху — селектор проєктів → **New Project**.
3. Назва будь-яка, наприклад `youtube-translator` → **Create**.

### 3.2. Увімкніть YouTube Data API

1. Меню (☰) → **APIs & Services** → **Library**.
2. У пошуку наберіть `YouTube Data API v3` → відкрийте → натисніть **Enable**.

### 3.3. Налаштуйте екран згоди (OAuth consent screen)

1. Меню → **APIs & Services** → **OAuth consent screen** (може називатися **Google Auth Platform**).
2. **User Type**: **External** → **Create**.
3. Заповніть мінімум: **App name** (будь-що), **User support email** (ваша пошта), **Developer contact email**.
4. Натискайте **Save and Continue** на кожному кроці (Scopes можна пропустити).

### 3.4. Додайте пошти до Test users — ОБОВ'ЯЗКОВО

Поки застосунок у режимі **Testing**, Google пускає до нього **лише користувачів, чиї пошти ви явно додали**. Інакше буде `Access blocked: access_denied`.

1. У **OAuth consent screen** (або **Google Auth Platform → Audience**) знайдіть **Test users**.
2. Натисніть **+ Add Users**.
3. Введіть **пошту свого Google-акаунта каналу** (і пошти всіх, хто користуватиметься скриптом).
4. **Save**.

> ⚠️ У режимі Testing токен живе **7 днів**, потім скрипт попросить увійти знову. Набридло? Натисніть **Publish App** на екрані згоди — вхід працюватиме без обмежень (Google може показати попередження про неперевірений застосунок — для особистого користування просто «Advanced» → «Go to the app»).

### 3.5. Завантажте client_secrets

1. Меню → **APIs & Services** → **Credentials**.
2. **+ Create Credentials** → **OAuth client ID**.
3. **Application type**: **Desktop app** (не Web і не Android!).
4. Назва будь-яка → **Create** → **Download JSON**.
5. Перейменуйте файл на **`client_secrets.json`**.
6. Покладіть його до папки **`data`** поруч зі скриптом.

> 💡 Керуєте **кількома каналами**? Для кожного потрібен власний `client_secrets.json` (з акаунта того каналу) і власний профіль. Файли можуть називатися по-різному — скрипт питає ім'я файлу при створенні профілю та сам знаходить будь-які `client_secrets*.json` у `data/`.

## Крок 4. Підключіть перекладача

Скрипт сам визначає провайдера за файлом ключа, який ви створите в `data/`.

### Варіант А — CodeCraft API (рекомендую: стабільно, швидко, дешево)

1. Зареєструйтеся на https://codecraftapi.com (безкоштовний тариф: 1 млн токенів/місяць ≈ 60 повних перекладів).
2. **Dashboard → API Keys → Create Key**. Ключі починаються з `cc_` і показуються **один раз** — одразу скопіюйте.
3. Створіть **`data/codecraft_api.json`** (ключ у лапках!):

```json
{ "CODECRAFT_API_KEY": "cc_ваш_ключ" }
```

4. Модель за замовчуванням: `deepseek-v4-flash-0731` (якість за $0.12 за мільйон токенів ≈ півцента за відео). Інші моделі: https://codecraftapi.com/models, зміна — через `codecraft_model` у `data/local_llm.json`.

### Варіант Б — ключі Gemini від Google (безкоштовно)

1. Зайдіть на https://aistudio.google.com/apikey.
2. **Create API key** → скопіюйте (починається з `AIza...`).
3. Створіть **кілька ключів** — вони працюють пулом з автоматичною ротацією.
4. Створіть **`data/gemini_api.json`**:

```json
{ "GEMINI_API_KEY": "AIza_ключ1, AIza_ключ2, AIza_ключ3" }
```

> Gemini іноді відповідає «модель перевантажена» — скрипт терпляче повторює, прогон іде трохи довше. CodeCraft стабільніший.

## Крок 5. Перший запуск

### Windows

Двічі клацніть **Запустить (Windows).cmd**.

### macOS

1. Відкрийте Термінал, наберіть `chmod +x ` (з пробілом), перетягніть у вікно файл **Запустить (Mac).command**, натисніть Enter. Це разова дія.
2. Далі просто двічі клацайте файл.
3. Якщо macOS каже, що файл з інтернету: Системні налаштування → Конфіденційність і безпека → «Усе одно відкрити».

### Майстер першого запуску

1. **Мова** — English / Українська / Русский.
2. **Ваше ім'я** — як до вас звертатиметься скрипт.
3. **Назва профілю** — будь-яка.
4. Скрипт сам знайде ваш `client_secrets*.json`.
5. **Playlist ID** — необов'язково (Enter — пропустити).
6. Відкриється браузер — **увійдіть в Google-акаунт каналу**. Якщо Google попередить про неперевірений застосунок: Advanced → Go to the app.
7. Готово — токен збережено в `data/tokens/`, повторних входів не буде.

Доки налаштування не завершено, у меню доступні **лише Налаштування**. Налаштування завершено, коли вибрано мови перекладу та додано ключ перекладача.

## Меню

| Пункт | Що робить |
|---|---|
| **Переклад** | Бере актуальні назву/опис відео, локалізує їх вибраними мовами та застосовує назад. |
| **Додати до плейлиста** | Додає відео до плейлиста профілю. |
| **Відкладена публікація** | Ставить відео в відкладену публікацію на дату. |
| **Налаштування** | Мова інтерфейсу, ваше ім'я, мови перекладу, кількість одночасних перекладів. |

## Файли та папки

```
youtube-metadata-translator/
├── yt_metadata_translator.py ← сам скрипт
├── Запустить (Windows).cmd   ← запуск на Windows
├── Запустить (Mac).command   ← запуск на macOS
├── requirements.txt          ← список бібліотек
├── README.uk.md              ← цей гайд
└── data/                     ← усі дані (файли ключів створюйте тут)
    ├── local_llm.json        ← налаштування перекладача
    ├── client_secrets.json   ← ключі Google (крок 3.5)
    ├── codecraft_api.json    ← ключ CodeCraft (крок 4, варіант А)
    ├── gemini_api.json       ← ключі Gemini (крок 4, варіант Б)
    ├── channel_profiles.json ← профілі каналів (створиться сам)
    ├── metadata.json         ← остання перекладена назва/опис
    ├── localizations.json    ← останній набір перекладів
    ├── ui_settings.json      ← мова інтерфейсу та ваше ім'я (створиться сам)
    └── tokens/               ← збережені входи в Google (створиться сам)
```
