# YouTube Metadata Translator — гайд по установке и запуску

Инструмент для YouTube-каналов: переводит название и описание видео на 12+ языков через нейросеть (Gemini, DeepSeek или локальную модель), обновляет метаданные видео, добавляет видео в плейлист и ставит отложенную публикацию на выбранные дни недели.

Работает на Windows и macOS. Всё, что нужно — бесплатное или почти бесплатное.

---

## Что понадобится (5 минут чтения, ~30 минут настройки)

1. **Python 3.10 или новее** — сам язык, на котором написан скрипт.
2. **Google-аккаунт**, которому принадлежит YouTube-канал.
3. **Ключ для перевода** — один из вариантов:
   - [CodeCraft API](https://codecraftapi.com) — самый стабильный вариант, есть бесплатный тариф;
   - ключи Gemini от Google — бесплатны, но иногда перегружены.
4. ~30 минут времени на настройку (делается один раз).

---

## Шаг 1. Установи Python

### Windows

1. Зайди на https://www.python.org/downloads/ и нажми жёлтую кнопку **Download Python 3.x.x**.
2. Запусти скачанный установщик.
3. **САМОЕ ВАЖНОЕ:** на первом экране поставь галочку **«Add python.exe to PATH»** (внизу окна). Без неё ничего не заработает.
4. Нажми **Install Now** и дождись конца установки.
5. Проверка: нажми `Win + R`, введи `cmd`, нажми Enter. В чёрном окне набери `python --version` и Enter. Должно показать что-то вроде `Python 3.13.1`. Если пишет «не является командой» — переустанови и не забудь галочку из пункта 3.

### macOS

1. Зайди на https://www.python.org/downloads/ — сайт сам определит, что у тебя Mac, и предложит нужную версию. Скачай и установи как обычную программу.
2. Проверка: открой **Терминал** (Cmd + Пробел, набери «Терминал», Enter), набери `python3 --version`. Должно показать версию.
3. Вместе с Python автоматически установится `tkinter` (нужен для окна вставки описания) — ничего дополнительно делать не надо.

## Шаг 2. Установи библиотеки для скрипта

### Windows

Открой командную строку (`Win + R` → `cmd` → Enter) и вставь одну команду:

```
pip install -r "путь_к_папке\requirements.txt"
```

Вместо `путь_к_папке` подставь, где лежит папка `data` рядом со скриптом. Проще всего: открой папку `data` рядом со скриптом в Проводнике, кликни по адресуной строке сверху, скопируй путь оттуда и вставь в команду.

### macOS

В Терминале:

```bash
pip3 install -r путь/к/папке/requirements.txt
```

## Шаг 3. Создай ключи Google (client_secrets) — самый длинный шаг

Это ключи, которые разрешают скрипту управлять **твоим** YouTube-каналом. Делается один раз.

### 3.1. Создай проект в Google Cloud

1. Зайди на https://console.cloud.google.com под Google-аккаунтом твоего канала.
2. Сверху нажми на селектор проектов → **New Project** (Новый проект).
3. Название любое, например `youtube-translator`. Нажми **Create**.
4. Дождись создания и убедись, что проект выбран в селекторе сверху.

### 3.2. Включи YouTube Data API

1. Открой меню (три полоски слева сверху) → **APIs & Services** → **Library**.
2. В поиске набери `YouTube Data API v3`.
3. Кликни на него и нажми синюю кнопку **Enable** (Включить).

### 3.3. Настрой экран согласования (OAuth consent screen)

1. Меню слева → **APIs & Services** → **OAuth consent screen** (может называться **Google Auth Platform**).
2. **User Type**: выбери **External** → **Create**.
3. Заполни минимум:
   - **App name**: любое название, например `My Channel Manager`;
   - **User support email**: твоя почта (выбери из списка);
   - **Developer contact email**: твоя почта.
4. Жми **Save and Continue** / **Create** на каждом шаге (области доступа — Scopes — можно пропустить, ничего добавлять не нужно).

### 3.4. Добавь почты в тестовые пользователи — ОБЯЗАТЕЛЬНО

Пока приложение находится в режиме тестирования (**Testing**), Google пускает в него **только тех пользователей, чьи почты ты явно добавишь**. Если не добавить — при входе будет ошибка `Access blocked: access_denied`.

1. Там же в **OAuth consent screen** (или **Google Auth Platform → Audience**) найди раздел **Test users**.
2. Нажми **+ Add Users**.
3. Введи **почту своего Google-аккаунта** (того, где канал). Если скрипт будет использовать другой человек — введи и его почту тоже. Можно добавить несколько через запятую или по одной.
4. Нажми **Save** / **Confirm**.

> ⚠️ **Важно знать:** в режиме Testing токен доступа живёт **7 дней**, потом скрипт попросит войти заново (это нормально, просто снова войди в браузере). Если надоело переавторизовываться — на экране OAuth consent screen нажми **Publish App** (Опубликовать): тогда вход будет работать без ограничений по времени, но Google может пометить приложение как непроверенное — это нормально для личного использования, просто нажми «Advanced» → «Go to (название приложения)» при входе.

### 3.5. Скачай client_secrets

1. Меню слева → **APIs & Services** → **Credentials**.
2. Нажми **+ Create Credentials** → **OAuth client ID**.
3. **Application type**: выбери **Desktop app** (не Web и не Android!).
4. Название любое → **Create**.
5. В появившемся окне нажми **Download JSON** — скачается файл с длинным именем вроде `client_secret_1234567890-abc.apps.googleusercontent.com.json`.
6. Переименуй его в **`client_secrets.json`**.
7. Положи этот файл в папку **`data`** рядом со скриптом (в папке `data` рядом со скриптом). Если папки `data` нет — создай её.

> 💡 Если нужно управлять **несколькими каналами** — для каждого канала нужен свой `client_secrets.json` (можно от разных Google-аккаунтов) и свой профиль в скрипте. Файлы можно называть по-разному, например `client_secrets_channel2.json` — имя файла спросит скрипт при создании профиля.

## Шаг 4. Подключи переводчик

Скрипт переводит тексты через нейросеть. Нужен API-ключ одного из сервисов. Скрипт сам поймёт, какой ключ ты добавил.

### Вариант А — CodeCraft API (рекомендую: стабильно, быстро, копейки)

1. Зарегистрируйся на https://codecraftapi.com (есть бесплатный тариф — 1 миллион токенов в месяц, этого хватит на ~60 полных переводов).
2. Зайди в **Dashboard → API Keys → Create Key**. Ключ начинается с `cc_` и показывается **один раз** — сразу скопируй.
3. В папке `data` создай файл **`codecraft_api.json`** с таким содержимым (ключ в кавычках!):

```json
{ "CODECRAFT_API_KEY": "cc_твой_ключ_сюда" }
```

4. Модель по умолчанию — `deepseek-v4-flash-0731` (отличное качество за $0.12 за миллион токенов, ~полцента за видео). Хочешь другую модель — полный список с ценами: https://codecraftapi.com/models, менять через `codecraft_model` в файле `data/local_llm.json`.

### Вариант Б — ключи Gemini от Google (бесплатно)

1. Зайди на https://aistudio.google.com/apikey под своим Google-аккаунтом.
2. Нажми **Create API key** → скопируй ключ (начинается с `AIza...`).
3. Можно создать **несколько ключей** — они работают пулом: если один упирается в лимит, скрипт автоматически переключается на следующий.
4. В папке `data` создай файл **`gemini_api.json`**:

```json
{ "GEMINI_API_KEY": "AIza_ключ1, AIza_ключ2, AIza_ключ3" }
```

> Обрати внимание: Gemini иногда отвечает «модель перегружена» — скрипт сам терпеливо повторяет, просто прогон идёт чуть дольше. CodeCraft стабильнее.

## Шаг 5. Первый запуск

### Windows

Дважды кликни **«Запустить (Windows).cmd»**.

### macOS

1. Открой Терминал, набери `chmod +x ` (с пробелом), перетащи в окно файл **«Запустить (Mac).command»**, нажми Enter. Это нужно один раз, чтобы система разрешила запуск.
2. Теперь дважды кликай по этому файлу.
3. Если macOS скажет «файл нельзя открыть, так как он из интернета»: Системные настройки → Конфиденциальность и безопасность → внизу кнопка «Всё равно открыть».

### Создание профиля канала

При первом запуске скрипт попросит:

1. **Channel profile name** — любое имя профиля, например `my_channel`.
2. **Client secrets filename** — жми Enter, если назвал файл `client_secrets.json` (как в гайде).
3. **Playlist ID** — ID плейлиста, куда автоматически добавлять видео (можно пропустить — Enter). ID — это часть ссылки на плейлист после `list=`.
4. Откроется браузер с просьбой войти в Google — **войди в аккаунт канала**. Если увидишь «Google не проверил это приложение» — нажми **Continue** / «Дополнительные настройки» → «Перейти на приложение».
5. Готово — скрипт запомнит тебя (токен сохранится в `data/tokens/`) и больше не будет спрашивать вход.

### Выбери языки

В главном меню выбери **6) Настройки языков перевода** → **1) Отметить языки в списке**. Введи номера нужных языков через запятую (например `1,5,7,9`), `A` — выбрать все, `0` — готово.

Здесь же пунктом **4** можно настроить, сколько языков переводить одновременно (подсказка покажет допустимый максимум по числу твоих API-ключей).

## Как пользоваться (главное меню)

| Пункт | Что делает |
|---|---|
| **1) Последнее видео** | Берёт с последнего видео канала актуальное название и описание, переводит их на выбранные языки и применяет к этому же видео. После — добавление в плейлист и вопрос про отложенную публикацию. |
| **2) Конкретные видео** | То же самое, но для видео по ссылкам (можно несколько через запятую). Берёт перевод из локальных файлов. |
| **3) Все видео** | Массовое обновление всех видео канала (или последних N). Видео короче минуты пропускает. |
| **4) Локализуй название и описание** | Ручной ввод текста: набери название и вставь описание — скрипт переведёт и сохранит в файлы, чтобы потом применить пунктами 2–3. |
| **5) Отложенная публикация по ссылке** | Ставит видео в отложенную публикацию на выбранную дату. |
| **6) Настройки языков перевода** | Выбор языков и настройка параллельности. |

**Типовой сценарий:** загрузил видео с нормальным названием/описанием → пункт 1 → жди перевод → видео на всех языках готово.

**Отложенная публикация:** скрипт спросит дату в формате `ддммгг` (например `151026` = 15 октября 2026) и поставит публикацию на время из календаря (файл `data/publ_calendar_имя_профиля.json` — там можно задать своё время для каждого дня недели). Публикация разрешена только в понедельник, среду, пятницу и воскресенье — это легко поменять, попроси того, кто тебе передал скрипт.

## Если что-то пошло не так

| Ошибка | Что делать |
|---|---|
| `Access blocked: access_denied` при входе | Твоя почта не добавлена в Test users — см. шаг 3.4, добавь её и попробуй снова. |
| `invalid_grant` или вечный запрос логина | Удали файл из `data/tokens/` (он называется как твой профиль) и запусти заново — войдёшь по-новой. |
| `Лимит квоты на сегодня превышен` | Дневная квота YouTube API исчерпана, придёт в себя завтра (сброс по тихоокеанскому времени). |
| `Нет файла data/codecraft_api.json` / «не содержит ключ» | Не создан файл ключа переводчика — см. шаг 4. Ключ должен быть в кавычках! |
| `Expecting value: line 1 column ...` при запуске | В одном из `data/*.json` файлов опечатка (чаще всего ключ без кавычек). Открой файл и проверь формат. |
| Окно вставки описания не открывается (Mac) | Переустанови Python с python.org — в стандартном установщике tkinter есть, в самосборном может не быть. |
| `python: command not found` (Mac) | Установи Python по шагу 1, используй `python3` вместо `python`. |

## Файлы и папки

```
youtube-metadata-translator/
├── yt_metadata_translator.py ← сам скрипт
├── Запустить (Windows).cmd   ← запуск на Windows
├── Запустить (Mac).command   ← запуск на macOS
├── requirements.txt          ← список библиотек
├── README.md                 ← этот гайд
└── data/                     ← все данные (создай файлы ключей здесь)
    ├── local_llm.json        ← настройки переводчика
    ├── client_secrets.json   ← ключи Google (шаг 3.5)
    ├── codecraft_api.json    ← ключ CodeCraft (шаг 4, вариант А)
    ├── gemini_api.json       ← ключи Gemini (шаг 4, вариант Б)
    ├── channel_profiles.json ← профили каналов (создастся сам)
    ├── metadata.json         ← последнее переведённое название/описание
    ├── localizations.json    ← последний набор переводов
    └── tokens/               ← сохранённые входы в Google (создастся сам)
```

Приятного использования! 🧙
